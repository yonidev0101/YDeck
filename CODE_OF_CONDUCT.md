# Code of Conduct

YDeck follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and respectful, assume good intent, and keep discussions about the work. Harassment, insults and
personal attacks are not accepted, in issues, pull requests or anywhere else the project is discussed.

To report something, write to yonidev0101@gmail.com. Reports are read by the maintainer and kept confidential.
